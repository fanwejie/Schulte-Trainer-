# 舒尔特方格训练工具（Schulte Trainer）

Win11 风格（浅色 / 深色 / 跟随系统可切换的 Fluent 界面）的舒尔特方格训练工具，浏览器访问，局域网内所有设备可用。

本说明区分两种形态：

- **源码版（即本 Git 仓库）**：纯代码，不含内置运行时。运行需要电脑装有 Node.js（≥18），执行 `node server.js`；
  也可以自行放入 `runtime\node\node.exe`（约 89MB）后直接双击 `start.bat`。
- **完整免安装版**：在源码版基础上加入 `runtime` 文件夹得到的绿色包。目标电脑**不需要安装任何软件**，
  把整个文件夹拷到任意 Windows 电脑（64 位），双击 `start.bat` 即可运行。

## 功能（当前版本）

- **登录**：只需输入一个名字即可进入；首次输入自动注册。
- **自动登录**：同一台设备（同一浏览器）下次访问时自动登录，无需再输入。
- **训练**：3×3 ~ 8×8 方格规格可选；点击“开始训练”后先显示数字 1，从按下 1 起计时，按顺序点击数字，点错有晃动/变色提示。
- **成绩评级**：完成后按用时给出 A–F 等级与对应标语（详见下方“成绩等级说明”）。
- **历史成绩**：右上角时钟按钮查看；按规格分组记录，支持列表与“最佳/平均/最差”折线趋势图、时间范围筛选与清空。成绩保存在服务端 `data\records.json`，换设备用同名登录也能看到。
- **设置**：主题（浅色/深色/跟随系统）、数字大小、数字字体、界面语言（中/英/日/韩/西），均按用户名保存并跨设备同步。

> 用户注册名保存在服务端的 `data/users.json`（为按人保存训练数据预留）。

## 运行方式

### 运行（两种方式任选其一）

- **完整免安装版**：直接**双击 `start.bat`**（需目录内存在 `runtime\node\node.exe`），不需要装 Node.js、不需要联网。
- **源码版（Git 克隆）**：本机装有 Node.js 时，命令行执行：

  ```
  node server.js
  ```

启动成功后会自动打开浏览器进入本机页面；黑色窗口会显示局域网访问地址，**不要关闭它**（关闭即停止服务）。

若用内置运行时，命令行等价于：`runtime\node\node.exe server.js`

### 局域网访问（其它电脑 / 手机 / 平板）

1. 在“服务器电脑”上双击 `start.bat` 并保持窗口开启。
2. 启动后会打印类似地址：`局域网访问： http://192.168.1.100:3000`
3. 其它设备连接**同一个 WiFi（同一局域网）**，用浏览器打开上面的 `http://<局域网IP>:3000` 即可。

> 局域网内其它设备只是用浏览器打开网页，不需要安装任何东西。

### 分发完整免安装版到别的电脑

- 在完整免安装版（含 `runtime`）上，把**整个文件夹**拷贝到目标电脑任意位置；
- 双击 `start.bat` 即可，目标电脑无需安装 Node.js。
- 目标电脑需为 Windows 64 位（x64）。

## 常见问题

**Q：其它设备打不开？**
- 确认设备与服务器电脑在同一局域网（同一路由器 / 同一 WiFi）。
- 首次运行 Windows 会弹出“防火墙”提示，务必勾选 **专用网络** 并点击 **允许**。
  若已错过，可在 Windows 安全中心 → 防火墙 → 允许应用通过防火墙 → 允许 `Node.js`（专用）。
- 确认服务窗口打印出的端口与地址一致。

**Q：想换一个端口？**
```
runtime\node\node.exe server.js 8080
```
或编辑 `start.bat`，把 `server.js` 后加上端口号：`"%NODE_CMD%" server.js 8080`。

**Q：80/443 之外还有防火墙或路由限制？**
请把端口改为可用的数字并放行对应端口。

**Q：不想自动打开浏览器？**
设置环境变量后启动：`set NO_OPEN=1` 再运行，或在 `start.bat` 中加一行 `set NO_OPEN=1`。

**Q：双击 `start.bat` 后提示找不到 node.exe？**
- 说明当前是源码版且目录里没有 `runtime\node\node.exe`：请先安装 Node.js（≥18）后用 `node server.js` 启动；
  或获取完整免安装包（含 `runtime`）再双击。
- 完整免安装版务必整体拷贝（含 `runtime`），不要只拷 `start.bat`。
- 若黑窗口一闪而过，请确认已正确放置 `runtime`，然后重新双击。

**Q：换一个用户怎么登录？**
点击右上角头像 → “切换用户”，输入新名字即可。切换后同一设备不会自动登录上一用户。

## 成绩等级说明（A–F）

完成一局后按用时评级，标准以 5×5（25 格）为基准（参考 12–14 岁组 16″优秀/26″中等/36″需强化的常见资料，
成年人与训练有素者应更快），其它规格按格子数等比换算：

| 等级 | 5×5 用时 | 评价 |
| --- | --- | --- |
| A | ≤ 15 秒 | 鼓励语（绿） |
| B | ≤ 25 秒 | 鼓励语（蓝） |
| C | ≤ 36 秒 | 调侃（红） |
| D | ≤ 50 秒 | 调侃（红） |
| E | ≤ 70 秒 | 调侃（红） |
| F | > 70 秒 | 调侃（红） |

> 各档秒数与 A–F 的调侃/鼓励文案都可在 `public\js\app.js` 顶部的
> `GRADE_LIMITS` 与 `GRADE_SLOGANS` 中自行调整（例如给小朋友用可放宽）。

## 目录结构

```
start.bat            # 双击启动（优先用内置运行时，无则回退系统 Node）
server.js            # 服务端（Node 内置模块，零第三方依赖）
runtime\node\node.exe   # 内置 Node.js 运行时（完整免安装版才有；源码版可不含，约 89 MB）
public\              # 前端页面（原生 HTML/CSS/JS）
  index.html
  css\style.css
  js\app.js
data\users.json      # 用户注册名（首次运行时自动生成）
data\records.json    # 历史成绩（按用户、按规格分组，首次保存时自动生成）
```

> 本 Git 仓库为源码版，不含 `runtime`（避免仓库过大）；发布“完整免安装版”时把 `runtime` 放入同目录即可。

## 说明

- “兼容性拉满”的思路：把可移植的 Node.js 运行时打进包里，整包拷贝即用。
- 如需**单个 .exe 文件**（不留 `runtime` 文件夹）也可做，但那需要联网下载打包工具
  （本机当前无外网时做不了）；若需要，请在有网环境把工具下载好再打包。
- 前端为原生实现，无需构建工具；更换/升级页面后直接覆盖 `public` 下文件即可。
